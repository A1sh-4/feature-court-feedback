# Security / セキュリティ

## English

If you find a security problem in Feature Court (https://feature-court.a1sh-4.workers.dev), please **do not open a public issue**.

Report it privately instead:
1. Go to the [Security tab](https://github.com/A1sh-4/feature-court-feedback/security) of this repository.
2. Choose **Report a vulnerability**.

Please include what you found, how to reproduce it, and what someone could do with it. Don't include real case links or other people's data. AISH will reply through the private report.

Please don't test against cases that aren't yours, and don't try to overload the service.

## 日本語

Feature Court（https://feature-court.a1sh-4.workers.dev）にセキュリティ上の問題を見つけた場合は、**公開issueを作らないでください**。

代わりに、非公開で報告してください。
1. このリポジトリの[Securityタブ](https://github.com/A1sh-4/feature-court-feedback/security)を開きます。
2. **Report a vulnerability** を選びます。

見つけた内容、再現手順、悪用された場合の影響を書いてください。実際のケースのリンクや他の人のデータは含めないでください。AISHが非公開の報告スレッドで返信します。

ご自身のもの以外のケースで試したり、サービスに過度な負荷をかけたりしないでください。
